## Gate note (T170)

The whole chain is implemented and tested:

- discovery, authority, retrieval, applicability, extraction, grounding, injection defenses, verification, persistence and UI.

What is still missing is any **real provider** behind the ports:

- a discovery provider;
- an OCR/AI extractor;
- verified official-domain registry entries.

These need the G1 runtime-provider approval ("When a real runtime provider becomes necessary to continue V1, stop at that approval gate and present the options"). Without them, the production app honestly shows "no verified official source" and gives no professional recommendations.
