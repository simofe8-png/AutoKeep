## Key findings

1. **Delek (Mazda, Ford, NIO):** the prior lead is confirmed and extended. All three sites publish a public index of importer service-plan PDFs: Mazda 19 entries, Ford 23, NIO 2. The index gives model and model-year range, and engine for some entries. Every PDF is a `delekmotorscoil.sharepoint.com` link that redirects to a Microsoft sign-in. Prior research described the Mazda plans as a "JS form, no endpoint"; that is wrong. The index is server-rendered, and the real blocker is the SharePoint login.
2. **Champion Motors publishes a schedule.** `championmotors.co.il/service-routine/` has static HTML tables covering all VW-group brands. This reverses the prior "NO_SOURCE_FOUND" for Škoda and VW. The tables are keyed by engine displacement and fuel, not by model or year. The terms require prior written permission for crawlers, copying, storage, processing and building a database.
3. **Geely Israel (Geo Mobility)** is the most complete source found. It publishes per-model Hebrew maintenance-schedule PDFs as static links, plus owner manuals, warranty booklets and workshop/maintenance manuals. The terms use the same "without prior written permission" template as Champion.
4. **MG:** prior findings re-verified. There is still no maintenance document type.
5. **BYD:** the importer is Shlomo Motors on bydauto.co.il (byd.co.il is dead). The site has static Hebrew manuals, and its HTML states a routine that it says supersedes the manuals.
6. **Chery (Carasso):** nothing usable is published.
7. **Jaecoo/Omoda (Colmobil):** the manuals sit behind an e-mail form in the UI.
